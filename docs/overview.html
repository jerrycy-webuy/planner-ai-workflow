02架构核心：一份产品主数据，处处渲染

Planner 改数据只改一处（Lark Base / ProductSpec），行程 PDF、Skybear 字段、文案培训全部重新渲染即得 —— 直接消灭「多处手抄、多日期摊算、变动重算」三大痛点。

A1市场雷达 P2

每周竞品扫描按区域切分推送 + 接入 Skybear 自有销售 / lost deal 数据（目前完全没用上）。

Out 每周一每人一份区域机会简报（试运行 3–4 周后定是否进 Product Committee 例会）

A2立项一页纸 低

一句话方向 → 竞品价带 + 历史销售 + BU 定位校验 → 立项 brief。

Out 目的地 / 天数 / 目标价带 / 预期 margin / 竞品对比

A3报价转录官 P0

地接 Excel / Word / PDF 报价 → 归一化入 Quotes 表 + 漏项检查 + 多家比价表。

Out Quote_Lines 明细（日期段 × 人数档 × 单价）+ 砍价点提示

A4Costing 引擎 P0

毛利倒推 + 竞品对标并排；档位规则一次定义全日期生成；改一个成本全日期重算 + 低毛利红旗。

Out 每 Tour Code 成本 + 5 价格档 + Margin 红旗视图

webuy-itinerary skill v3：地接中文行程 → TourSpec → 双语 PDF（电子版 + 印刷版）+ 可编辑校样。

A6Skybear 发布器 P0→P1

A7销售弹药生成器 P1

三件套同源生成：群发图文 + 卖点卡/FAQ/异议话术 + 培训材料。

Out 每周砍班 / 加班 / 调价建议，lost deal 摘要回流 Product Committee
