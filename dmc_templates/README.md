# 地接社（DMC）资料与报价填写模板

| 文件 | 给谁 | 表头语言 | 预填内容 |
|---|---|---|---|
| `WEBUY_DMC_Template_Korea.xlsx` | 韩国地接 | 中文 / English / 한국어 | 来自 `korea/kb`：竞品在售线路出现过的 **88 家酒店、245 个景点**（核心 → 常见 → 可选）、14 道常见团餐、**20 条 ≥2 条线路走过的城市路段** + 15 项机场/内陆航班/KTX/渡轮、24 个季节节庆与假期、购物站、6 条询价线路（K01/K03–K07 骨架 × 5 个人数档） |
| `WEBUY_DMC_Template_Taiwan.xlsx` | 台湾地接 | 繁體中文 / English | WEBUY 整理的台湾团体常用清单：72 个景点、环岛路段与高铁/台铁、15 个季节节庆（含台风季、苏花/太鲁阁管制）、购物站与自费、4 条询价线路（环岛 8 天、北台湾 5 天、中南部 6 天、台北日月潭台中 6 天） |

台湾目前没有竞品抓取数据，预填清单是常识整理，请地接修正补充；之后按韩国同样方法抓台湾竞品时，把 `seed_taiwan.py` 换成知识包即可。

## 工作表（两版结构相同）

| 表 | 对应 WEBUY 系统 | 内容 |
|---|---|---|
| 填写说明 | — | 用途、颜色约定、币种与日期格式、交回方式 |
| 1 供应商信息 | Lark **Suppliers** + Quotes 表头 | 执照、联系人、24h 紧急电话、可操作区域、导游语种、车队、清真能力、报价币种与有效期、付款与取消条款 |
| 2 酒店 | 知识包 hotels | 每家每季一行：房型、双/单/三人房每间每晚、加床、早餐、儿童政策、团体最少间数、保留房与释放期 |
| 3 景点门票 | 知识包 attractions | 门票/团体价、开放时间、休息日、预约、建议停留、季节限制、大巴停车、清真友好 |
| 4 餐食 | — | 团餐菜单、每人价、清真/素食/不含牛肉、可容纳人数 |
| 5 用车交通 | 知识包 city_graph | 车型日租、超时、机场接送、城市路段车程与价格、内陆航班/KTX/高铁/渡轮团体票 |
| 6 导游领队 | Departures 杂费（Tips / Tour Leader Cost） | 导游日薪、餐补、建议小费、FOC |
| 7 购物与自费 | — | 购物站停留与人头费、「免购物」加价、自费项目价格（用于常规版 / 纯玩版两套报价） |
| 8 季节节庆 | 知识包 seasons；Departures Season 档 | 2027 确切日期、酒店加价、是否不能接团、地接建议 |
| 9 行程报价 | Lark **Quotes / Quote_Lines** | 一行 = 询价线路 × 出发期段 × 人数档：成人双人房、单房差、儿童占床/不占床、三人房、FOC、含项；绿色列按 Lists 参考汇率自动算 SGD 参考价 |
| 10 逐日行程 | ItinerarySpec（A5） | 地接建议的逐日安排，WEBUY 用它生成行程并跑校验器 |
| Lists | — | 下拉选项、参考汇率（蓝字黄底，可改） |

**颜色**：黄 = 地接填写 · 灰 = WEBUY 预填（勿改） · 绿 = 公式 · 第 5 行浅灰斜体 = 示例（不读入）。第 4 行灰色小字是字段 key（与 Lark 字段 / 知识包字段同名），A3 报价转录官按它读回，请勿删除。

## 重新生成

```bash
pip install openpyxl opencc-python-reimplemented   # opencc 用于台湾版繁体
python3 dmc_templates/build_dmc_templates.py        # 读 korea/kb，输出两个 xlsx 到本目录
```
知识包更新后重跑即可刷新韩国版预填。
