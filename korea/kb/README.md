# korea kb：生成行程用的韩国线知识包

由 `scripts/build_kb_kr.py` 从四站整理结果生成（2026-10-08）。字段与日本版 `Japan-Tour-Planner/kb` 一致，可直接给同一套 skill / 校验器使用。

| 文件 | 内容 | 条数 |
|---|---|---|
| `families.json` | 14 个标准行程家族：骨架（城市+夜数）、天数带、USD 价格带、成员、形态、来源、主题、覆盖城市、归并说明 | 14 |
| `tours.json` | 53 条线路紧凑版：route、逐日（城市/出发地/交通/景点/含餐/住宿）、酒店、购物站、含项、价格 | 53 |
| `city_graph.json` | 过夜城市节点 + 交通边（出现次数、方式、示例）+ `daytrip_reach`（住 A 城去 B 城景点的次数）+ 主要路段参考时长 | 27 节点 / 48 边 |
| `attractions.json` | 景点池：城市、区域、类别、核心/常见/可选、出现线路、家族、来源站；`generic=true` 为韩服/购物站等不限城市的体验 | 359 |
| `hotels.json` | 分城市分档酒店：group_standard（新加坡跟团）/ premium（小团高端）/ fit（自由行）/ join_in（地接拼团） | 25 城 |
| `stats.json` | 节奏先验（全部 / 跟团两套）：每天景点数、天数→城市数、1 晚停留占比、移动日占比、首站分布、跟团购物站占比 | — |
| `seasons.json` | 季节 / 节庆硬约束 | 19 |

## 口径
- 景点等级：核心 = 出现 ≥4 条线路；常见 = 2–3 条；可选 = 1 条或仅在词典（未见在售线路，`sites` 标「词典」）。
- 价格：`tours.json` 的 price 已折 USD（1 SGD = 0.78），note 里保留原币原价。
- 首末日为国际航班日，不计入节奏统计。新加坡出发的韩国跟团 Day 1 多为红眼航班（stay 为 null）。
